Overview Proyek

ARAHIN adalah platform navigasi inovatif yang dirancang khusus untuk mempermudah kelompok rentan dan penyandang disabilitas dalam bermobilitas menggunakan transportasi publik. Sistem ini mengintegrasikan pencarian rute multi-transit cerdas serta layanan pendamping fisik langsung (real-time guide) secara terstruktur.

Rute Cerdas Multi-Transit

Menyediakan opsi rute langsung hingga transit 2 kali menggunakan Bus, Kereta, LRT, dan MRT.

Fasilitas Aksesibilitas Dinamis

Penyaringan rute cerdas menyesuaikan kebutuhan disabilitas (wheelchair slot, lift, ramp, priority seat, gerbong wanita).

Layanan Pemandu Fisik

Sistem pemesanan & langganan pendamping jalan (Guide) terverifikasi, lengkap dengan integrasi payment gateway.

Aksesibilitas Tampilan

Mendukung High Contrast Mode (Kuning/Hitam/Putih) dan penyesuaian ukuran huruf dinamis di seluruh halaman.

Teknologi yang Digunakan

Komponen Teknologi Utama & Layanan
Frontend React 18, TypeScript, Vite 7, TailwindCSS 3, Radix UI, TanStack React Query v5
Backend Node.js, Express.js v5 (REST API)
Database MySQL (Aiven Managed Cloud Database) dengan ssl connection pool
Keamanan & Auth JSON Web Token (JWT) & Hashing Bcrypt
Eksternal API Midtrans Client SDK (Pembayaran), Brevo API (SMTP Verifikasi & Reset Password)
Testing Jest (Unit & Route Testing dengan coverage minimal 80%)
