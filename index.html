Tentang Saya

Saya adalah mahasiswa Teknik Informatika (Semester 6) yang berfokus pada bidang Data Analytics dan Web Development. Saya memiliki passion dalam mengolah data mentah menjadi wawasan bisnis yang intuitif, memodelkan prediksi data, serta mengembangkan aplikasi web yang modern, responsif, dan aksesibel.

Melalui proyek akademik maupun eksplorasi mandiri, saya terbiasa membangun end-to-end data pipeline—mulai dari web scraping otomatis, pembersihan data, analisis sentimen (NLP), hingga visualisasi dashboard interaktif menggunakan Python, Streamlit, dan Plotly. Di sisi pengembangan web, saya berpengalaman menggunakan React, TypeScript, Tailwind CSS, serta integrasi REST API dan basis data (MySQL & PostgreSQL/Supabase).
