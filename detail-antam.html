Overview Proyek

Sistem ini dirancang untuk memberikan transparansi dan proyeksi harga emas Antam secara real-time serta otomatis. Dengan menggabungkan pipeline scraping harian, model time-series forecasting, dan cloud database, pengguna dapat mengambil keputusan investasi emas dengan informasi yang lebih akurat.

Automated Scraper

Pengambilan data harga aktual dan ketersediaan stok emas Antam secara otomatis setiap hari melalui GitHub Actions.

AI Price Forecasting

Otomatisasi Pipeline Data

Pipeline dieksekusi secara otomatis setiap hari menggunakan GitHub Actions melalui langkah-langkah berikut:

1

Ekstraksi Data: Scraping data harga emas terbaru dan stok pecahan berdasarkan lokasi butik.

2

Penyimpanan Database: Transformasi data dan pengiriman ke database cloud Supabase PostgreSQL.

3

Pelatihan Model: Melatih kembali model time-series Prophet menggunakan histori data terintegrasi.

4

Hasil Forecasting: Menghasilkan proyeksi tren dan nilai prediksi harga 7 hari ke depan.

Jadwal cron otomatis dikonfigurasi berjalan setiap pukul 10:25 WIB (UTC+7).

Evaluasi Model Forecasting

Model forecasting dievaluasi menggunakan metrik Mean Absolute Percentage Error (MAPE) untuk mengukur tingkat keakuratan hasil prediksi terhadap harga emas harian aktual.

Nilai MAPE Tingkat Akurasi
< 10% Sangat Akurat (Highly Accurate)
10–20% Baik
20–50% Cukup
> 50% Kurang Akurat

Skema Data (Supabase PostgreSQL)

Data hasil scraping dan forecasting disimpan terstruktur pada 5 tabel utama:

harga_antam_harian — Catatan harga emas harian

historis_harga_antame — Histori komprehensif harga

stok_antam_butik — Stok per butik & pecahan

prediksi_harga_antam — Hasil forecast model Prophet

detail_prediksi — Rincian komponen tren & batas bawah/atas
